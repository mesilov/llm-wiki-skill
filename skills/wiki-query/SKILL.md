# Ответ по wiki

Прочитай [контракт](references/contract.md). Найди ответ в знаниях и проверь
основания. Запрос ответа не разрешает сохранять его в wiki или журнале.

1. Прочитай индекс и схему, если она есть. Ищи также по тексту, названиям и
   синонимам: индекс может быть неполным. Если индекс отсутствует, продолжи
   доступный поиск и назови ограничение; не создавай его в режиме запроса.
2. Прочитай относящиеся страницы. Для точной цитаты, спорного вывода или
   изменяемого факта открой первичный источник; не ограничивайся пересказом.
3. Сопоставь даты, версии и область действия. Сохранённый снимок показывает
   известное на его дату. Для вопроса «сейчас» проверь актуальный источник
   доступными средствами только для чтения. Если не удалось — сообщи дату
   доступных сведений и ограничение, не выдавай их за текущие.
4. Ответь прямо, со ссылками на конкретные страницы и основания. Различай
   сведения источника, собственный вывод, предположение и принятое решение.
   Покажи существенные противоречия и неизвестные.

Пример: на вопрос о текущем лимите годичный снимок позволяет ответить
«в сохранённой версии — 100; актуальное значение не подтверждено», если
свежая проверка недоступна. Он не позволяет подтвердить лимит 100 сегодня.

Для добавления источника нужен `wiki-ingest`, для правки знаний — `wiki-update`.
