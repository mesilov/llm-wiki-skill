# Добавление источника

Прочитай [контракт](../wiki-query/references/contract.md) и
[формат источников](../wiki-query/references/raw.md). Работа начинается
с переданного материала; самостоятельное исследование не запускай автоматически.

1. Прочитай индекс и схему, если она есть. Сравни новый материал с сохранёнными
   по происхождению, версии и содержанию. Для точного повтора используй старый
   снимок, но проверь, отражён ли он в знаниях.
2. Получи доступное содержание. Недоступную ссылку не пересказывай по догадке:
   сохрани только известные сведения с пометкой о недоступности, если запрос
   охватывает сохранение ссылки. Идею пользователя обозначь как идею, не факт.
3. Сохрани новый источник и контекст получения. Новую версию того же URL
   сохрани отдельно, оригинал не перезаписывай. Отдели свои пояснения от источника.
4. Найди затронутые страницы через индекс и текст. Уточни канонические знания,
   добавляя ссылки на основания. Сохрани противоречия и условия применимости;
   непроверенный вывод обозначь как гипотезу. Не меняй статус решения молча.
5. Обнови затронутую навигацию и существующие метастраницы. Проверь источник
   через raw-lint, ссылки через lint и выводы по содержанию. Для поиска влияния
   можно использовать `bin/wiki/affected <путь-источника>`; результат неполон.

Пример: новая редакция статьи меняет лимит со 100 до 200. Сохрани обе версии
и укажи, к каким датам и условиям относятся значения. Без этих оснований
нельзя просто заменить 100 на 200 во всех страницах.

Сообщи путь источника, обновлённые страницы, что изменилось в знаниях,
сохранённые противоречия и результат проверок. Точный повтор может не требовать записи.
