# Проверка минимального комплекта — 2026-11-11

## Область

Локальная адаптация донора, без установки в пользовательские проекты,
публикации, push или изменения донора. Исходный донор прошёл 284 unittest.
Рабочее дерево донора осталось чистым.

## Автоматические проверки

Команда: `python3 -m unittest discover -s tests -t .`.
Итоговый прогон: 80 тестов, все прошли; Python 3.14.7.
Без PyYAML три теста raw-lint пропускаются, а не падают.

Покрытие сокращённого комплекта:

- Обычные и reference-style Markdown-ссылки, исключение блоков кода,
  относительные пути, symlinks, граница вложенного Git checkout, явный корень.
- Индекс и страницы без входящих ссылок, read-only отчёты, raw provenance,
  корректные даты, безопасный YAML и запрет повторных ключей.
- Установка, dry-run, повторная установка, конфликт до копирования,
  варианты agent, работа установленного CLI вне checkout исходников.
- Updater main/release, закрепление SHA, сохранность корпуса, локальные правки
  содержания/прав/удалений, --yes, --force, backup, rollback, недопустимые архивы,
  повреждённый manifest, недостающие ресурсы и лицензии, сбои сети.
- Побайтовое совпадение восьми исходных файлов SimpleEn-RU с manifest.

HTTP — единственная подменённая внешняя граница updater. Файловые операции
выполняются на реальных временных каталогах. Удалённый релиз не проверялся.
Синтаксис Python проверен с grammar 3.10; фактический прогон выполнен на Python 3.14.
Это не запуск на всех поддерживаемых версиях Python.

Четыре SKILL.md прошли `skill-creator/scripts/quick_validate.py`.
Локальные ссылки собственной документации проверены отдельно от upstream-примеров.

## Практические сценарии навыков

Независимый агент создал временный корпус и установил комплект через installer.
Он прочитал навыки, общий контракт и обязательные материалы SimpleEn-RU.

| Сценарий | Наблюдение |
| --- | --- |
| Query о текущем лимите по старому снимку | Назван лимит 100 для v1 и дата; актуальность не подтверждена; корпус не изменён |
| Ingest новой редакции с лимитом 200 | Новый снимок сохранён отдельно; v1 и v2 различены; применимость к v1 осталась неизвестной |
| Update двух значений «клиента» | Организация и приложение сохранили отдельные определения; входящие ссылки и якоря исправлены; raw не изменён |
| Lint страницы с выводом без источника | При коде CLI 0 обнаружен смысловой пробел; отчёт не изменил корпус |

Read-only шаги проверены снимками хешей, прав и времени изменения файлов.
Сырой отчёт и артефакты прогона хранились во временном каталоге на машине
проверки и не входят в репозиторий.

Это forward test, не доказательство улучшения относительно baseline.
Предварительный мысленный прогон имел контекст донора и не выявил достоверных
поведенческих провалов; он не засчитывается как чистый RED-эксперимент.
Практические сценарии близки к примерам навыков; устойчивость на иных задачах
и моделях не подтверждена. Полный SimpleEn-RU требует заметного контекста даже
для короткого query; его сохранение входит в запрос пользователя.

## Найденные и исправленные дефекты

- После ссылки на каталог повторно проверяется граница его README: symlink
  не позволяет считать внешнюю цель допустимой локальной ссылкой.
- Локальное удаление управляемого файла защищено от восстановления обычным
  обновлением; для восстановления требуется force.
- Каталоги с суффиксом `.md` не читаются как текстовые файлы.
- Повторные YAML-ключи provenance отклоняются, не подменяют источник молча.
- Архив без лицензии одного из навыков отклоняется до записи.

Для исправлений добавлены регрессионные тесты. Независимое ревью кода
проверило updater, installer и CLI; замечания обработаны до завершения.

- Installer dry-run не создал файлов; обычная установка создала четыре навыка,

  `update --force` скачал архив этой revision с GitHub и восстановил оригинал.

Отчёт `phase1.json`, сценарий `acceptance.py` и stdout/stderr каждого шага
хранились во временном каталоге на машине проверки и не входят в репозиторий.
