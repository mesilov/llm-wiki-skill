# Minimal LLM Wiki Kit — план реализации

**Цель:** самостоятельный комплект из четырёх wiki-навыков, механических проверок,
установщика, updater и полного встроенного SimpleEn-RU на основе локального донора.

**Архитектура:** `skills/wiki-{query,ingest,update,lint}` используют короткий общий
контракт. CLI работает с `raw/` и `knowledge/` от выбранного корня; профиль,
PDLC, OpenSpec и forge-диагностика не входят в комплект. CLI не оценивает истинность.
Updater управляет только установленными skills и `bin/wiki`, сохраняет корпус.

**Технологии:** Python 3.10+, стандартная библиотека; PyYAML только для raw-lint.
Markdown навыков и неизменённые исходные материалы SimpleEn-RU с лицензией.

## Согласованный состав и решения

- Четыре навыка: query (чтение), ingest (новый источник), update (существующие
  знания и навигация), lint (отчёт по умолчанию, исправления в рамках запроса).
- CLI: lint, status, find-orphans, affected, raw-lint, update. Убираем trace,
  doctor, PDLC-представления, обязательные статусы решений и сортировку глоссария.
- Сохраняем донорский разбор Markdown-ссылок и защиту путей. `--project` выбирает
  корень корпуса; не добавляем конфигурационный язык. Якоря и внешние URL проверяет агент.
- Raw: `raw/YYYY-MM-DD-slug/README.md`, исходные вложения рядом. Минимальные YAML
  поля: source (происхождение), retrieved (дата получения). Это локальное соглашение,
  не заявление соответствия OKF. Старые корпуса не мигрируются автоматически.
- Updater: main/release, pinned SHA, manifest, защита локальных правок, backup,
  откат при обрабатываемой ошибке записи. Добавляем `--yes` для разрешённого
  неинтерактивного обновления без разрешения перезаписывать локальные правки.
- Проверка обновлений выполняется по запросу, не перед каждым wiki-вопросом.
- Installer: явный `--agent`, Codex по умолчанию, без меню и legacy `--claude`.
  `--init-wiki` создаёт только raw README, схему и индекс знаний.
- SimpleEn-RU переносится целиком с manifest и лицензией; wiki-обвязка сохраняет
  приоритет смысла, фактов, цитат и исходных данных над стилем.

## Выполнение и критерии проверки

- [x] Перенести независимые тесты ссылок/updater, увидеть отсутствие реализации.
- [x] Адаптировать ядро CLI; проверить ссылки, code fences, symlinks, вложенные
  checkout, отчёты без записи, отсутствие обязательного профиля.
- [x] Перенести updater/manifest и сократить installer; проверить dry-run,
  конфликты, backup, rollback, повреждённые архивы, --yes и сохранность корпуса.
- [x] Написать четыре навыка и общий контракт, перенести SimpleEn-RU побайтово.
- [x] Проверить YAML навыков, ссылки ресурсов, хеши исходников и независимые
  сценарии query/ingest/update/lint во временном проекте.
- [x] Проверить установку и CLI вне checkout, прогнать unittest и whitespace.

Публикация, push, release и установка в рабочие проекты не входят в задачу.
HTTP updater проверяется на локальных ответах тестового сервера; это не подтверждает
наличие опубликованного комплекта в удалённом репозитории.
