# Работа с набором llm-wiki

Это репозиторий инструментов, не пользовательский корпус знаний.
Канонические навыки: `skills/wiki-*/SKILL.md`; общие материалы —
`skills/wiki-query/references/`; CLI — `bin/wiki/`; установщик — `scripts/install.py`.

Сохраняйте минимальный состав и границы чтения/записи. Не переносите предметные
данные проектов, PDLC/OpenSpec-интеграции и настройки публикации в defaults.
Существующая wiki не мигрируется автоматически. CLI подтверждает только
свои механические проверки, не смысл и не актуальность знаний.

Исходные материалы SimpleEn-RU в `utr-source/` сохраняйте вместе с лицензией
и manifest. Меняйте wiki-обвязку отдельно от upstream-материалов.

Проверки: `python3 -m unittest discover -s tests -t .`, `git diff --check`.
Для raw-lint нужен PyYAML из `bin/wiki/requirements.txt`. Новые untracked файлы
проверяйте на whitespace отдельно. Установку/updater проверяйте во временных
проектах, без записи в пользовательские wiki и без публикации.
